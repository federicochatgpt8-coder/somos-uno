# Somos Uno – Gestión de pedidos

App web instalable (PWA) para administradores y transportistas de Somos Uno.

- Ingreso con cuenta de Google (Google Identity Services).
- Los datos viven en Google Sheets/Drive; esta app solo muestra la pantalla.
- El servidor es un Apps Script (`Api.gs`) que verifica la cuenta y el rol en cada acción.
